# FlappyBall

A modern take on the classic Flappy Bird game, built with React Native and Expo.

## Features

- Player name input and leaderboard
- Smooth animations and physics
- Sound effects
- Modern UI design
- Persistent high scores

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Run on your preferred platform:
- Press 'a' for Android
- Press 'i' for iOS
- Press 'w' for web

## Game Controls

- Tap the screen to make the ball jump
- Avoid the pipes
- Try to get the highest score!

## Requirements

- Node.js 14 or later
- npm or yarn
- Expo CLI
- iOS Simulator (for iOS) or Android Emulator (for Android)

## Assets

Place the following files in the `assets` directory:
- `background.png` - Game background image
- `jump.mp3` - Jump sound effect
- `icon.png` - App icon
- `splash.png` - Splash screen image
- `adaptive-icon.png` - Android adaptive icon
- `favicon.png` - Web favicon
